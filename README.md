# brother-powertools
Interactive shell comprising a suite of Linux-based tools that work well with the Brother Super PowerNote word processor laptop.

# Main Menu
1. File Transfer
2. Internet
3. Games
4. BASIC
5. Email
6. Library

# File Transfer
Allows the user to recieve plain-text files from the Linux host for use in word-processing. File name is specified, the brother unit is placed in recieve mode, and the file is transmitted over the existing serial connection.

# Internet
A selection of internet utilities suited for the brother's teletype display.
- Wikipedia
-- The user specifies an article title and it is retrieved in plain text form. The user then specifies the amount of free space on the brother and the resultant plain text file is split into sections of that size, which can then be transferred to the brother's memory for printing, use in word processing or saved to disk.
- Wiktionary
-- Same functionality as Wikipedia; user can look up a word and then send the definition(s) to the brother as a WP file.
- Private Heaven II BBS
- Level29 BBS

# Games
- Adventure
- Star Trek
- Hunt the Wumpus
- Oregon Trail

# BASIC
Launches a full BASIC interpreter. Simple commands can be run in immediate mode or more complex programs can be entered by line and saved to the environment for future loading.

# Email
Custom-built email client tailored to the brother's display and workflow. Utilizes POP email access to Gmail.

# Library
Functional tracking of books, articles, and other sources both on the collection level and for research use.
